A Python program — standard library only, no network — that writes one line to /output/entry.txt: the perfect pickup line, as an AI agent would say it to a person. The line is 75 characters, inside the competition's gate of 1 to 200 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
